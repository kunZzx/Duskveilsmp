Plugin yang dibuat khusus untuk servermu

Bukan template. Setiap plugin ditulis sesuai konsep servermu — fitur, tampilan GUI, hingga pesan di game bisa kamu atur sendiri lewat config.

DuskCrates.java
// contoh plugin custom buatan kami
public class DuskCrates extends JavaPlugin {

  @Override
  public void onEnable() {
    saveDefaultConfig();
    getCommand("crate")
      .setExecutor(new CrateCommand(this));
    getLogger().info("DuskCrates aktif!");
  }
}

FAQ

Pertanyaan umum

Berapa lama pengerjaannya?

Website sederhana 2–5 hari, plugin tergantung kompleksitas fitur, setup server 1–3 hari. Estimasi pasti diberikan setelah pembayaran dikonfirmasi.

Plugin untuk versi Minecraft apa?

Paper, Spigot, dan Purpur. Sebutkan versi servermu di catatan pesanan, kami sesuaikan.

Apakah source code plugin diserahkan?

Ya, source code dan dokumentasi config diserahkan setelah pekerjaan selesai.

Metode pembayaran apa saja?

QRIS, GoPay, OVO, DANA, dan Virtual Account bank. Pembayaran terverifikasi otomatis.

Server saya lag parah, apa yang dikerjakan?

Kami cek TPS/MSPT, profiling dengan Spark, audit plugin, konfigurasi server, JVM flags, dan world. Kamu menerima laporan sebelum & sesudah optimasi.

Siap mulai proyekmu?

Pilih paket sekarang atau konsultasikan ide plugin & aplikasimu dulu.
